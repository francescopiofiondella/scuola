Collegamento a GitHub (da fare una volta sola)

Il token si crea su GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens. Scegli solo questo repository e il permesso Contents: Read and write. Chi ha il token può modificare il repository: non condividerlo.
